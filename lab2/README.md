\# Лабораторная работа №2



\## Тема

Классы, агрегация и композиция. Язык программирования с ручным управлением памятью.



\## Тема проекта

Проектирование системы управления кинотеатром.



\## Классы



Film — фильм  

Hall — кинозал  

Cinema — кинотеатр



\## Связи между классами



\### Композиция

Cinema — Hall



Класс Cinema содержит объект Hall как поле m\_hall.  

При уничтожении объекта Cinema объект Hall также автоматически уничтожается.



\### Агрегация

Hall — Film



Класс Hall хранит указатель Film\* m\_film на объект фильма, созданный отдельно.  

После уничтожения объекта Hall объект Film продолжает существовать.



\## Правила программы



\- длительность фильма должна быть больше 0;

\- фильм нельзя запустить, если он не назначен залу.



\## Файлы проекта



film.hpp, film.cpp — класс Film  

hall.hpp, hall.cpp — класс Hall  

cinema.hpp, cinema.cpp — класс Cinema  

lab2.cpp — демонстрация работы программы
